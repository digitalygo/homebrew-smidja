# homebrew-smidja

Homebrew tap for [Smidja](https://github.com/digitalygo/smidja), the Digitalygo coding harness.

## Install

```bash
brew install digitalygo/smidja/smidja
```

## Update

```bash
brew update && brew upgrade smidja
```

The formula builds from source on tag; macOS binaries from the GitHub
release can be installed manually if you prefer not to compile.
